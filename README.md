# Otic privacy policy

Public home of the privacy policy and terms of service for the Otic e-book & audiobook app,
served by GitHub Pages at
<https://skendora.github.io/otic-privacy/privacy-policy.html> and
<https://skendora.github.io/otic-privacy/terms-of-service.html>.

The sources of truth are `docs/privacy-policy.html` and `docs/terms-of-service.html` in the (private)
app repository; this repo only
publishes copies of them. Update them there first, then copy them here.
