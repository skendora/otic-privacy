# Otic privacy policy

Public home of the privacy policy for the Otic e-book & audiobook app, served by GitHub Pages at
<https://skendora.github.io/otic-privacy/privacy-policy.html>.

The source of truth is `docs/privacy-policy.html` in the (private) app repository; this repo only
publishes a copy of it. Update it there first, then copy it here.
